# ربات رأی‌گیری کتاب‌ها (نمونه اولیه)

## امکانات
- فهرست فعلی ۷۱ کتاب؛ قابل افزایش با ویرایش `books.json`
- نام و نام خانوادگی قبل از رأی‌گیری
- جست‌وجو، صفحه‌بندی و انتخاب چند کتاب
- ثبت یک رأی برای هر نام نرمال‌شده در پایگاه داده SQLite
- نتایج و خروجی CSV فقط برای مدیر مشخص‌شده با `ADMIN_ID`

## راه‌اندازی
این پوشه یک نمونه کد آماده است، نه یک ربات آنلاینِ از قبل میزبانی‌شده. برای فعال شدن باید یک بار آن را با توکن خودتان اجرا/میزبانی کنید.

1. در تلگرام به `@BotFather` بروید و `/newbot` را بزنید؛ نام و username ربات را تعیین کنید و توکن را بگیرید.
2. آیدی عددی تلگرام خودتان را با روشی مطمئن پیدا کنید.
3. Python 3.10+ نصب کنید.
4. در این پوشه اجرا کنید:
   `pip install -r requirements.txt`
5. متغیرهای محیطی را تنظیم کنید:
   - `BOT_TOKEN` = توکن دریافتی از BotFather
   - `ADMIN_ID` = آیدی عددی تلگرام شما
6. اجرا:
   `python bot.py`

روی ویندوز PowerShell:
```powershell
$env:BOT_TOKEN="توکن-ربات"
$env:ADMIN_ID="آیدی-عددی-شما"
python bot.py
```

## استفاده
- `/start` راهنما
- `/vote` شروع رأی‌گیری
- `/cancel` لغو رأی‌گیری
- `/results` نمایش رتبه‌بندی (فقط مدیر)
- `/export` دریافت CSV (فقط مدیر)

## نکات مهم امنیتی و محدودیت‌ها
- این نسخه، نام را به شکل نرمال‌شده هش می‌کند تا در جدول رأی‌دهندگان نام خام برای بررسی تکراری ذخیره نشود؛ با این حال نام نمایشی برای سوابق ذخیره می‌شود.
- جلوگیری از تکرار بر اساس نام و نام خانوادگی به‌تنهایی قابل دور زدن است (نام‌های متفاوت/غلط‌املایی) و ممکن است افراد هم‌نام را اشتباهاً رد کند. بهتر است در گروه خصوصی از شناسه کاربری تلگرام هم به‌عنوان قاعده تکمیلی استفاده شود یا مدیر فهرست مجاز اعضا را تعریف کند.
- رأی‌ها در فایل `votes.sqlite3` ذخیره می‌شوند. هنگام میزبانی، دیسک پایدار لازم است؛ در غیر این صورت ممکن است داده‌ها از بین بروند.
- توکن ربات را در گروه یا چت عمومی نفرستید.
- نتایج در گروه منتشر نمی‌شوند؛ فقط مدیر می‌تواند با دستورها نتایج را ببیند.
- قبل از استفاده واقعی، با چند حساب آزمایشی تست کنید.
